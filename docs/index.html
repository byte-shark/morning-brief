📱 iPhoneのホーム画面に追加する方法

ホーム画面に追加すると、Safariのアドレスバーが消えて本物のアプリとしてフルスクリーンでサクサク読めるようになります。

  1. Safari下部の共有ボタン（四角から矢印が出たアイコン 📤）をタップ
  2. メニューをスクロールして「ホーム画面に追加」をタップ
  3. 右上の「追加」を押せば完了！
